# CLAUDE.md

This file provides guidance to Claude Code when working with code in this repository.

## Project

Сайт-визитка (лендинг) для Романа Соттаева — горнолыжного инструктора и гида
в Приэльбрусье. Услуги: горнолыжные занятия, восхождения (Эльбрус),
треккинг, организация активного отдыха (джип-туры, конные прогулки,
экскурсии). Целевая аудитория — туристы, планирующие поездку в регион.

## Stack

- Чистые HTML, CSS, JS — без фреймворков и сборщиков
- Всё в одном файле (index.html): стили в <style>, скрипт в <script> в конце body
- Тёмная тема, адаптивная вёрстка
- Открывается напрямую в браузере, без сервера сборки

## Structure

Структура ещё меняется, актуальный список секций — по id в index.html
(hero, about, программы, FAQ, contact и т.д.). Не полагайся на этот список
как на фиксированный — сверяйся с файлом.

## Conventions

- Именование CSS-классов: BEM-подобное (напр. .job-card, .faq-item)
- Цвета — через CSS-переменные в :root (--bg, --ink, --navy и т.д.)
- Анимации появления — через класс .reveal + IntersectionObserver
- Фото — плейсхолдеры с классом .photo-slot, пока нет реальных фотографий

## Notes

- Пока нет системы сборки — если понадобится (например, для нескольких
  страниц), обсудить переход на что-то простое (Vite/статический генератор),
  не усложнять раньше времени.
